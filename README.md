# PAM Baruta · sitio y PWA (versión plana)

Todos los archivos van juntos, en la misma carpeta (sin subcarpetas). Súbelos tal cual a la raíz del repositorio.

- index.html: sitio completo
- print.html: hoja para imprimir
- sw.js y manifest.webmanifest: lo que hace instalable la app
- logo.svg, hoja.svg, hero.webp, baruta-blanco.png, nueve-once-blanco.png, favicon.svg: imágenes
- icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png, favicon-32.png, favicon-48.png, og-image.png: íconos

Pendientes al final de index.html: URL_REGISTRO (enlace del formulario) y PROXIMA_JORNADA (jornada).
